# PetroVale Energy — Portfolio Website Concept

A responsive fictional oil & gas corporate website built as a portfolio demonstration.

## Files
- `index.html` — site structure and content
- `styles.css` — responsive design, animations, typography, layout
- `script.js` — mobile menu, scroll reveal, animated metrics, demo contact form

## Run locally
Open `index.html` directly in a browser, or use a local static server such as VS Code Live Server.

## GitHub Pages
Upload the three files to the root of a GitHub repository, then enable **Settings → Pages → Deploy from a branch → main / root**.

## Notes
- PetroVale Energy and all project/company statistics are fictional.
- The contact form is intentionally a demo and does not transmit data.
- Photography is loaded from Unsplash and requires an internet connection.
